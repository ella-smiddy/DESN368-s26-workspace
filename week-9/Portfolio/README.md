# Ella Smiddy Portfolio

## Project Overview
This is my final Web Design I portfolio. It includes a homepage, selected project cards, a learning log, a reflection page, custom styling, responsive CSS, a favicon, and an academic integrity statement.

## Design Direction
The visual direction is based on my Moodz and Vibes Figma style tile. I kept the warm neutral palette, film-strip inspiration, rounded borders, stripe pattern, and soft vintage feeling, but refined it into a cleaner portfolio layout.

## Required Pages
- `index.html` — portfolio homepage
- `learning-log.html` — renamed weekly log page
- `reflection.html` — loop reflection page
- `CHECKLIST.md` — final self-assessment checklist
