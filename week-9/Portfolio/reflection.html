The Loop Reflection

What I learned this quarter

These answers connect my first design ideas to the portfolio I built with HTML and CSS.

The Threshold

The moment code started to click for me was when I understood that HTML is the structure and CSS is what makes that structure look designed. Before that, I was trying to make everything happen at once and it felt confusing. Once I started thinking in boxes, sections, classes, and styles, the process felt less random. I realized that my Figma layout could be translated into code one piece at a time.

The Pit

The hardest assignment for me was the Field Guide because I had to manage images, body text, colors, navigation, and layout all at the same time. I got stuck when things would not line up the way they did in my design. I got out of the pit by slowing down, fixing one section at a time, and asking for help when I needed it. That assignment taught me that debugging is part of the process, not proof that I am bad at coding.

The Pivot

My original Moodz and Vibes file had a vintage film-strip style with neutral colors, bold rounded type, stripes, and star details. I kept that same feeling because it still fits my personality and design taste. The biggest pivot was making it more usable for a real portfolio instead of only a moodboard. I simplified the palette, made the spacing cleaner, and turned the style into cards, buttons, and sections that can work on desktop and mobile.

The Process

If I could change my process, I would start earlier and organize my files better from the beginning. I learned that naming folders, keeping images in the right place, and writing simple code first makes the whole project easier. I would also spend more time reading the assignment requirements before designing. That would help me avoid rebuilding things later when I realize I missed something important.

The Future

This hybrid skillset will help me because I want to be a designer who understands how websites actually get built. Knowing HTML and CSS makes me more realistic when I design layouts in Figma. It also helps me communicate better with developers because I understand the basics of structure, responsiveness, and styling. In the future, I want to keep building projects that combine branding, marketing, and web design.
